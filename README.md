# AntiVirus-AKN

AntiVirus-AKN is an Expo React Native app focused on mobile security workflows such as device scanning, file scanning, and security center monitoring.

## Prerequisites

- Node.js (LTS recommended)
- npm
- Expo CLI (via `npx expo`)

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run start
   ```

## Available Scripts

- `npm run start` - Start Expo development server
- `npm run android` - Run on Android
- `npm run ios` - Run on iOS
- `npm run web` - Run in web browser
